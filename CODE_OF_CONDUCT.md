# Code of Conduct

Everchat is a small source-available project, not a policed community.
Maintainers will not moderate tone, police “unprofessional” language, or run a
warning system.

## Scope

This applies to the Everchat GitHub organization and other official project
spaces (issues, pull requests, discussions, and similar).

## Enforcement

The only enforcement action is a **permanent ban** from those spaces, and only
for **illegal** conduct.

There is no correction, warning, or temporary-ban ladder.

## Reporting

To report illegal conduct, contact [@erikfiala](https://github.com/erikfiala)
on GitHub, or use
[GitHub Security Advisories](https://github.com/erikfiala/everchat/security/advisories/new)
if the report should stay private.
