Install for Chrome

Get Everchat from the Chrome Web Store. That is the primary path, and we are publishing ASAP.

If the listing ever goes down because Google doesn't like what we do, you can still load a local build in developer mode as a fallback:

  1. Clone the Everchat repo and run pnpm install && pnpm build
  2. Open chrome://extensions and turn on Developer mode
  3. Load unpacked → select .output/chrome-mv3
  4. Pin Everchat and open the side panel on any page

Prefer the Chrome Web Store badge above once the listing is live. Passkeys use everch.at as the relying party, so keep this site live for sign-in.
