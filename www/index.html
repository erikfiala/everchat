Install for Chrome locally

Load a local build in developer mode while the store listing is on the way, or anytime you want a build you control:

The repo is currently private. Prefer the official Chrome Web Store link above instead.

  1. Clone the Everchat repo and run pnpm install && pnpm build
  2. Open chrome://extensions and turn on Developer mode
  3. Load unpacked → select .output/chrome-mv3
  4. Pin Everchat and open the side panel on any page
