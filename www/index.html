Install for Chrome

Chrome Web Store listing is coming soon. Until then, load the extension unpacked from a local build:

  1. Clone the Everchat repo and run pnpm install && pnpm build
  2. Open chrome://extensions and turn on Developer mode
  3. Load unpacked → select .output/chrome-mv3
  4. Pin Everchat and open the side panel on any page

When the listing goes live, the Chrome Web Store badge above will open it directly. Passkeys use everch.at as the relying party, so keep this site live for sign-in.
