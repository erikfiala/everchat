Install Everchat

Chrome Web Store listing is coming. Until then, install an official GitHub release zip. Loading that unpacked zip in developer mode also means you keep a copy if the store ever rejects or removes Everchat.

From a GitHub release

Download the latest Chrome zip from GitHub Releases.

  1. Download everchat-*-chrome.zip
  2. Unzip it. The folder must contain manifest.json
  3. Open chrome://extensions, turn on Developer mode, Load unpacked, select that folder
  4. Pin Everchat and open the side panel on any page

Source code

The GitHub repository is public so you can review the code, follow the changelog, and send contributions. Install only official GitHub Release zips or the Chrome Web Store listing. Building from source is for review and pull requests, not an alternate distribution.
